# IntLab: Confluence-Fassungen der Dokumentation

Zweck: einfügefertige Fassungen der Betriebs- und Anwenderdoku für Confluence Cloud (Ordner `docs/confluence/`).
Reihenfolge: `01-ueberblick.md`, `02-betrieb.md`, `03-lab-sicherheit.md`, `04-trainer-handbuch.md`, `05-inhalte-pflegen.md`, `06-lernwelt-nordwind.md`.
Quelle ist das Repository: Bei Änderungen an `README.md`, `docs/operations.md`, `docs/lab-sicherheit.md`, `docs/content-authoring.md`, `docs/lernwelt-nordwind.md` oder an Oberflächentexten des Trainer-Bereichs diese Fassungen nachziehen und die Stand-Zeile anpassen.
Einfügen: Datei öffnen, ab der Zeile `# …` kopieren und in eine leere Seite des Cloud-Editors einfügen (Überschriften, Tabellen und Codeblöcke werden übernommen); die „Stand“-Zeile als ersten Absatz setzen, den Seitentitel selbst eintragen.
Die Dateien enthalten keine Bilder, kein HTML und keine relativen Links; Dateipfade stehen als Code.
